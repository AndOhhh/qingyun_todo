# 轻云 · Qingyun Todo

一个**纯本地**的 Flutter 待办软件（Todo app）：iOS 风格的界面、SQLite 存储、无账号、无服务端、无网络权限。

核心特色是**自定义天数周期**——一个周期可以是 N 天（也可以是周 / 月 / 年），周期内每一天可以安排不同的事项；到点由系统闹钟发本地提醒。

## ✨ 功能

### 待办
- 逾期 / 今天 / 明天 / 后续 / 已完成 **五分组**，空组不渲染，「已完成」默认折叠
- 优先级（无 / 低 / 中 / 高）+ 色带颜色（默认跟随优先级，可单独指定 8 色）
- **完成与删除严格分离**：绿色圆圈即时完成（可逆、无确认）；删除走编辑页动作卡 → 二次确认 → **5 秒撤销**
- 周期实例的**三级删除**：只删这一次 / 删该事项的未来待办 / 删整个周期
- 编辑页点「标记完成/取消完成」即落库并**直接返回上一页**

### 周期
- 类型：每天 / 每 2 天 / 自定义天数 / 每周 / 每 2 周 / 每月 / 每年（MONTH/YEAR 走日历算术，月末收敛，不做 30 天近似）
- **一轮一期**：只保证「当前轮」实例存在，本轮完成或整轮逾期才推进，待办页不会堆满未来项
- 周期项（模板）按「第 N 天」分组管理；改规则时**已完成实例不动、未完成计划重建**
- 暂停 / 终止 / 三层删除语义；删除后保留已完成历史（孤儿记录）
- **墓碑表**保证「删掉的这一次」不会在下次生成时复活
- 未来 3 轮预览（与生成引擎共用同一套规则）

### 日程
- 自绘月历：周日开头、相邻月补位可点按跳月、单周折叠、左右滑动翻月、点标题选月份
- 农历 / 节气 / 传统节日 / **法定假日「休/班」角标**（`tyme`）
- 日期标记：逾期红 / 未完成蓝 / 全部完成绿；1 条圆点、多条数字
- 当日安排：0–24h 时间轴刻度 + 紧凑卡片（可直接勾选）+ 当月概览 + 「今」按钮

### 统计
- 今日完成率（环形）/ 连续打卡（里程碑 3·7·14·30·60·100·180·365）/ 本周完成率（7 格点阵）/ 逾期任务（0 条绿色正向态）/ 待处理总数 / 周期完成率
- 图表：完成趋势（今天=小时 / 本周·本月=天 / 全部=月）、优先级分布、星期分布、月历热力
- 范围切换只作用于图表；分母为 0 显示 `--`

### 提醒通知
- 系统级排期（Android `USE_EXACT_ALARM`，iOS `UNUserNotificationCenter`），App 被杀仍到点
- 幂等 `reconcile`：改时间 / 完成 / 删除自动收敛；24h 补发窗口 + `is_notified` 防重复
- 国产 ROM 兜底：前台 15s 巡检只修 OS 丢单；「通知收不到？」诊断页按品牌给出自启动 / 耗电管理路径
- 点击通知打开对应待办（含**冷启动**）

## 🧱 技术栈

| 层 | 选型 |
| :-- | :-- |
| UI | Flutter 3.41 / Dart 3.11（Material 结构 + Cupertino 视觉） |
| 状态 | `flutter_riverpod`（不引入代码生成） |
| 存储 | `sqflite` + `path_provider`（4 表 / 7 索引 / 外键级联） |
| 通知 | `flutter_local_notifications` + `timezone` + `flutter_timezone` |
| 图表 | `fl_chart` |
| 农历 | `tyme` |

架构：`pages → stores（读） / logic（写） → repositories → db_helper`。
业务 SQL 只出现在 `repositories/`；写操作统一走 `stores/invalidation.dart` 的失效矩阵。

```
lib/
├── models/        纯数据模型 + 周期算术（CycleRule）
├── repositories/  DAO / 生成引擎 / 轮次策略 / 墓碑 / 统计聚合
├── stores/        Riverpod provider + 失效矩阵 + 启动编排
├── logic/         写操作编排（完成 / 删除 / 周期增删改）
├── services/      通知 / 系统设置通道 / 厂商识别
├── components/    跨页 UI（表单、选择器、浮动按钮、空错态）
└── pages/         待办 / 周期 / 日程 / 统计 / 通知引导
```

## ⚠️ 已知限制（1.0）

| 项 | 说明 |
| :-- | :-- |
| 统计口径 | 待办页按「一轮一期」隐藏旧轮实例，但「逾期 / 待处理 / 周期完成率」仍是全库口径，数字可能大于可见逾期数 |
| iOS 通知上限 | 系统只保留最近 64 条，已限制排最近 60 条；更远的提醒在下次打开 App 时重新排期 |
| 法定假日数据 | `tyme` 内置数据覆盖到 **2026-10-10**，新一年安排公布前可能没有「休/班」角标（农历/节气不受影响） |
| 国产 ROM | ColorOS / HyperOS / HarmonyOS 等需手动允许「自启动 / 完全后台行为」，否则系统会推迟或丢弃闹钟（应用内有引导页） |
| 数据库迁移 | DB `version = 1`，1.0 之后任何表结构变更都必须升级版本并补迁移 |
| 平台 | 仅针对手机竖屏设计；桌面端为脚手架，未做适配 |

## 📝 版本记录

### v1.0.0 · 2026-10-21

首个公开版本。

**功能**
- **待办**：逾期/今天/明天/后续/已完成五分组；优先级 + 色带颜色；完成与删除严格分离（删除二次确认 + 5 秒撤销）；周期实例三级删除
- **周期**：每天 / 每 2 天 / 自定义天数 / 每周 / 每 2 周 / 每月 / 每年；一轮一期；规则变更保留已完成、重建未完成；暂停与终止；删除后保留已完成历史
- **日程**：自绘月历（农历 / 节气 / 法定假日 / 调休）、相邻月补位跳转、单周折叠、当日 0–24h 时间轴、当月概览
- **统计**：今日完成率、连续打卡（里程碑）、本周点阵、逾期 / 待处理 / 周期完成率；完成趋势、优先级分布、星期分布、月历热力
- **通知**：系统级排期、24h 补发窗口、前台兜底巡检、国产 ROM 诊断引导页、点击通知直达对应待办（含冷启动）
- **品牌**：应用图标（蓝渐变 + 白云 + 琥珀对勾）与配套启动页

**发布前修复**
- 取消完成后重启会静默删除下一轮待办（数据丢失）
- 周期「当前轮」存在两套口径（周期页 vs 待办页/生成引擎）
- 逾期实例的「删除未来待办」会删错范围
- 「已完成」折叠箭头方向、1.3x 字号布局、长周期详情页大量空白
- 通知冷启动不跳转、Android 通知栏图标白块、iOS 超出 64 条被丢弃

**已知问题**：见上方「已知限制」。
