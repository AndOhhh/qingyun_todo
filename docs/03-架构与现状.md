```
                                    ├─ pages/todo/index.dart ─┬─ widgets/todo_card.dart → components/todo_tag.dart

                                    └─ pages/statistics/index.dart  (占位)
                                          models/todo.dart ← 被 todo 页与卡片共同引用
```

**目标分层**（Phase 1–2 落地，详见 [04-数据层与CRUD.md](./04-数据层与CRUD.md)）：

```
pages/  ← 只渲染与派发意图，不写业务规则
  ↑
stores/     (Riverpod：db_providers / todo_store / periodic_store)
  ↑
repositories/  (DAO：TaskRepository / PeriodicRepository / PeriodicItemRepository / StatisticsRepository)
  ↑
utils/db_helper.dart  (sqflite 单例、onCreate 建表、onUpgrade)
  ↑
models/  (Todo / Periodic / PeriodicItem / Subtask，字段与 DB v2 对齐)
```

## 5. 数据模型现状 vs DB v2

`lib/models/todo.dart` 当前定义（mock 用 VO）与 [02 schema v2](./02-数据库设计.md) 的差异：

| Dart 现状 | DB v2 | 落地时处理 |
| :-- | :-- | :-- |
| `String id` | `INTEGER id` | 改为 `int` |
| `String? note` | `remark` | 重命名对齐 |
| `DateTime? dueDate` | `remind_date`（+ `remind_time`） | 拆分日期与时间 |
| `bool isOverdue` | 无此字段 | 改为按 `remind_date < today && !isCompleted` **派生计算** |
| `int subDone` / `subTotal` | **无对应字段** | **移除**（Q2 决策：去除子任务功能，每条待办都是独立任务）→ 见 R11 |
| `TodoPriority priority` | `priority` TEXT | 存 `enum.name`，读取时 `values.byName()` |
| `Color accentColor` | `accent_color` TEXT | 存 `#RRGGBB`，需 String ↔ Color 转换工具 |
| `bool isPeriodic` | `source_type` | 由 `source_type == 'PERIODIC'` 派生 |
| `bool done`（**可变**，非 final） | `is_completed` | 建议改不可变 + 返回新对象，避免 `setState` 直接改字段 |
| — | `cycle_index`、`periodic_item_id`、`completed_at`、`sort_order`、`is_notified` | 新增 |

> `Todo.done` 目前是唯一的可变字段，`_toggle()` 直接改它再 `setState`。接入数据库后应改为不可变模型 + Repository 写回，否则 UI 与库中状态会不一致。

## 8. 开发规范

- 遵循 `flutter_lints`（`analysis_options.yaml` 已 `include: package:flutter_lints/flutter.yaml`）。
- 文件名 `snake_case`，类型名 `PascalCase`，私有成员 `_` 前缀。
- 类与公共方法用 `///` 文档注释，关键技巧加行内注释（现有 `todo_card.dart` 的同心圆角注释是好范例）。
- 待办用 `// TODO:` 标记（现有 `_handleAdd()` 已如此）。
- **文档维护约定**：涉及 `lib/` 结构、依赖、实现进度的改动，需同步更新本文 §1 / §3 / §6；涉及表结构的改动，需同步更新 [02](./02-数据库设计.md) 的变更记录表。文档元信息统一写"基于提交 `<短 hash>` 核对"，不写无法验证的手工日期。
