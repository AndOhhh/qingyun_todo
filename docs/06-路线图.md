## Phase 3 · 周期模块 ✅

**实际交付**：周期列表（进度、下次提醒、启停开关）、周期新增/编辑（预设 + 自定义天数 + 起始/终止日 + 备注）、周期详情（统计卡 + 按天分组增删改 + 近期实例）、条件删除（保留已完成实例）、轮次完结判定与下一轮生成。

**关键口径（与早期设计不同）**

1. **一轮一期（N13）**：只保证「当前轮」实例存在；本轮完成才生成下一轮；整轮逾期则顺延到今天所在轮；错过轮的实例保留在库、不在待办页展示。
2. **规则/日期变更（N14）**：起始日 / 间隔 / 事项天序 / 提醒时间变化时，**已完成实例保持不变**，未完成计划按新规则从「今天所在轮」重建；其余字段（标题、备注、优先级、色带）不追溯。
3. **删除后不复活（墓碑表）**：删除单条 / 删除未来实例会写 `periodic_skips`；撤销删除会清墓碑。
4. **取消完成后不丢下一轮（N21）**：生成路径不再「收敛清理」晚于本轮的实例，避免「取消完成 → 重启 → 下一轮待办消失」。
5. **「当前轮」单一口径（N21）**：周期列表/详情的进度统一走 `PeriodicRoundPolicy`，与待办页、生成引擎同源。

**验收（测试覆盖）**

- 每 2 天 + 第 1/2 天事项 → 只生成本轮 2 条；
- 重复生成幂等（唯一索引 + `ON CONFLICT DO NOTHING`）；
- 完成整轮 → `completed_count` 重算（绝对口径，不是 ±1）且生成下一轮；取消完成会回退；
- 暂停后停止生成，已有实例保留；重新启用补生成本轮；
- 删除周期：未完成实例删除、已完成实例置空外键并保留快照名；
- 每月周期日号锚定 + 月末收敛；`day_offset` 越界阻止保存（Q12）。

> 注意：MONTH 的 `day_offset` 上限是 **27**（`minCycleLength = 28`）。docs 早期示例里的 `day_offset = 28` 只能通过直接写库构造，UI 不可达。

## Phase 4 · 日程页 ✅

**实际交付**

- **自绘月历**（未引入 `table_calendar`）：周日开头、农历/节气/节日小字、法定假日「休/班」角标；
- 月历首尾补相邻月日期（灰色，可点按跳月）；月 ↔ 单周折叠；左右滑动翻月；标题点按弹出月份选择器；
- 日期标记：红 = 有逾期未完成、蓝 = 有未完成、绿 = 全部完成；1 条圆点、>1 条数字角标；
- 当日安排：**0–24h 时间轴刻度** + 紧凑卡片 `ScheduleTaskCard`（不是 `TodoCard`），可勾选、点按进编辑页；
- 当月概览（总数 / 已完成 / 完成率）、「今」按钮、右下角新增（预填选中日期）。

**与原计划的偏差**：`table_calendar` → 自绘；标记点**不区分**常规/周期（只有逾期/未完成/全部完成三态）；「月视图 + 周视图切换」→ 仅「月 ↔ 单周折叠」；左滑删除已移除。
