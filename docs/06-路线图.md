## Phase 1 · 数据层落地

**目标**：待办页从 mock 切换为真实数据库读写，并修掉阻断性风险。

**交付物**
- 依赖：`sqflite`、`path_provider`、（测试）`sqflite_common_ffi`；同时处理 `dio` 去留（**Q3**）。
- `utils/db_helper.dart`（含 `PRAGMA foreign_keys = ON`）、`utils/date_util.dart`、`utils/color_util.dart`。
- `models/`：`Todo` 改造（`id: int`、`note→remark`、拆 `remindDate`/`remindTime`、`isOverdue` 改派生 getter、`done` 改不可变、**移除 `subDone`/`subTotal`，`isPeriodic` 改派生**）+ 新增 `Periodic`、`PeriodicItem`、`CycleRule`（周期算术纯函数，可单测）。

**验收标准**
1. 全新 clone 后 `flutter run` 可直接构建成功（R1 已修）。
2. 首次启动自动建库建表，`PRAGMA foreign_keys` 为 ON（级联删除生效）。
3. 待办页数据来自数据库，杀掉 App 重启后勾选状态保留。
4. 今日进度统计的是 `remind_date = today` 的任务（R5 已修）。
5. `flutter test` 通过，覆盖 04 §7 中的"幂等性/外键级联/CHECK 约束/进度聚合"用例。

**验收标准**
1. 新增→列表出现→编辑生效→勾选完成写入 `completed_at`→删除后消失且重启不复活。

4. 分组按 Q10 呈现，空分组不渲染；今日进度只统计 `remind_date = today`。
5. 优先级与色带由用户可选而非硬编码；`已逾期` 标签由日期实时派生。
6. 卡片不再出现 `x/y` 子任务标签（R11 已清理）。
7. 表单校验（标题非空、时间格式）有明确提示。

## Phase 3 · 周期模块

**目标**：实现 FR-10 ~ FR-15，把 schema v2 的核心价值落地。

**交付物**：周期列表页（卡片：名称、周期文案、起始日、已完成轮数、本轮进度 `x/y`、下次提醒、启停开关）；周期新增/编辑页（名称、起始日、**周期类型预设 每天/每 2 天/每周/每 2 周/每月/每年/自定义（Q14）**、终止日、备注）；周期项管理页（按"第 N 天"分组增删改，含 `validateIntervalChange` 越界拦截 **Q12**）；`PeriodicRepository` / `PeriodicItemRepository`；`generatePeriodicInstances` 生成器与四个触发时机；`onInstanceCompleted` / `onInstanceUncompleted` 轮次完结与回退（**Q13**）；**删除周期/周期项的条件删除（保留已完成实例）**。

**验收标准**
1. 建"每 2 天，第 1 天 09:00 喝牛奶 / 第 2 天 09:00 喝豆浆"，待办页出现未来 30 天内正确日期序列的实例（对照 [01 §4.4 示例 1](./01-需求规格.md)）。
2. 重复触发生成不产生重复行（唯一索引 + `ON CONFLICT DO NOTHING`）。
3. 完成某轮全部实例后 `completed_count` +1 且生成下一轮。
4. 暂停周期后不再生成新实例，已有实例保留。
5. **删除周期 → 未完成实例被删、已完成实例保留**（`periodic_id`/`periodic_item_id` 置 NULL，`cycle_index` 与 `periodic_name_snapshot` 保留），周期项模板清空；确认弹窗前置展示"删除 N 条 / 保留 M 条"。
6. 孤儿历史记录在待办页显示为"周期·{快照名}"、无跳转入口，可取消完成或删除，且仍计入历史统计。
7. 修改 `interval_type`/`interval_value` 后已生成实例日期不变（**Q8**），新轮次按新规则生成。
8. **每月周期**：`start_date = 2026-09-01` 时轮起始日为 10-01、11-01…（日号锚定，非 30 天累加）；`start_date = 2026-01-31` 时第 2 轮为 `2026-02-28`（月末收敛，不得为 03-03）。
9. `day_offset >= cycleLength(k)` 时该轮跳过该项（对照 [02 §7.4 示例 2](./02-数据库设计.md)）。
10. 缩短周期导致周期项越界时阻止保存并列出冲突项（**Q12**）。
