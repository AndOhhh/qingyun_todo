| :-- | :-- |

| 形态 | **单机版**：本地 SQLite 存储，无服务端、无账号体系、无多端同步 |

## 2. 术语表

| 术语 | 定义 | 数据落点 |
| :-- | :-- | :-- |
| 常规待办 | 用户手动指定日期的一次性待办 | `tasks.source_type = 'REGULAR'` |
| 周期 | 以天为单位的循环规则：名称 + 起始日 + 周期天数 | `periodic_configs` |
| 周期类型 | `interval_type`（DAY/WEEK/MONTH/YEAR）+ `interval_value`，如"每 2 天""每周""每月" | `periodic_configs.interval_type` / `interval_value` |

| 孤儿记录 | 来源周期已被删除、但作为历史保留的已完成周期实例 | `tasks`：`source_type='PERIODIC' AND periodic_id IS NULL` |

## 4. 周期规则（核心算法）

> 业务规则见本节；字段定义与 SQL 见 [02-数据库设计.md](./02-数据库设计.md)；实现细节见 [04-数据层与CRUD.md](./04-数据层与CRUD.md)。

### 4.1 周期类型与预设（Q14 已决策）

| UI 文案 | `interval_type` | `interval_value` | 一轮天数 |
| :-- | :-- | --: | :-- |
| 每天 | DAY | 1 | 1（固定） |
| 每 2 天 / 自定义天数 | DAY | N | N（固定） |
| 每周 | WEEK | 1 | 7（固定） |
| 每 2 周 | WEEK | 2 | 14（固定） |
| 每月 | MONTH | 1 | 28–31（**按自然月**，日号锚定 `start_date`） |
| 每年 | YEAR | 1 | 365–366（**按自然年**） |

不采用"每月 = 30 天"近似：3 个月即漂移 1–2 天，"每月 1 号交房租"会逐步跑到 2 号、3 号。

### 4.2 实例推算

```
cycleStart(k)：                                     // k = 0,1,2,…
  DAY   → start_date + k × interval_value 天
  WEEK  → start_date + k × interval_value × 7 天
  MONTH → start_date 加 (k × interval_value) 个月，日号锚定；目标月无该日号则取该月最后一天
  YEAR  → start_date 加 (k × interval_value) 年，同上（2/29 → 2/28）

cycleLength(k) = cycleStart(k+1) − cycleStart(k)     // MONTH 为 28–31，YEAR 为 365–366
实例提醒日期   = cycleStart(k) + item.day_offset 天
生成前置条件   = is_active = 1 且 (end_date IS NULL OR remind_date <= end_date)
幂等保证       = UNIQUE(periodic_item_id, cycle_index) + ON CONFLICT DO NOTHING
```

⚠️ MONTH/YEAR 的日历算术**必须在 Dart 层实现**：SQLite 的 `date(x,'+1 month')` 对月末溢出是进位而非收敛（实测 `2026-01-31 +1 month = 2026-03-03`）。详见 [02 §7.1](./02-数据库设计.md)。

### 4.3 `day_offset` 约束（Q12 已决策）

- 保存校验：`0 <= day_offset < minCycleLength`（DAY/WEEK 取精确值，**MONTH 取 28，YEAR 取 365**）。
- 生成时若 `day_offset >= cycleLength(k)`，该轮**跳过该项**（如"每月第 29 天"在 2 月不存在）。
- 缩短周期导致已有周期项越界时：**阻止保存**，列出冲突项让用户先调整。
- MONTH/YEAR 且 `day_offset >= 28` 时 UI 提示"短月份可能跳过该事项"。

### 4.4 示例

**示例 1**：`start_date = 2026-09-25`，每 2 天；项 A `day_offset=0` 喝牛奶 09:00，项 B `day_offset=1` 喝豆浆 09:00。

| 轮次 | 轮起始日 | 生成实例 |
| :-- | :-- | :-- |
| 0 | 2026-09-25 | 09-25 09:00 喝牛奶　/　09-26 09:00 喝豆浆 |
| 1 | 2026-09-27 | 09-27 09:00 喝牛奶　/　09-28 09:00 喝豆浆 |
| 2 | 2026-09-29 | 09-29 09:00 喝牛奶　/　09-30 09:00 喝豆浆 |

**示例 2**：`start_date = 2026-09-01`，每月；项 A `day_offset=0` 交房租，项 B `day_offset=28` 月末盘点。

| 轮次 | 轮起始日 | 轮长度 | 生成实例 |
| :-- | :-- | --: | :-- |
| 0 | 2026-09-01 | 30 | 09-01 交房租　/　09-29 月末盘点 |
| 1 | 2026-10-01 | 31 | 10-01 交房租　/　10-29 月末盘点 |
| 5 | 2027-02-01 | 28 | 02-01 交房租　/　**跳过**（`day_offset=28` ≥ 28） |

### 4.5 删除与完成语义（Q5 / Q9 / Q13 已决策）

| 操作 | 结果 | 统计 |
| :-- | :-- | :-- |
| 标记完成 | 记录保留，`completed_at` 写入 | 计入分母与分子 |
| 取消完成 | `completed_at` 置 NULL；周期实例回退 `completed_count` | 移出分子 |
| 删除单条待办 | **物理删除**（无论是否已完成） | 从分母与分子同时消失 |
| 删除周期项 | 未完成实例删除；**已完成实例保留**并断开关联 | 已完成记录继续计入历史 |
| 删除周期 | 未完成实例删除；周期项模板级联删除；**已完成实例保留**为孤儿历史记录（保留 `cycle_index` 与周期名快照） | 已完成记录继续计入历史 |

三级删除入口（周期实例）：**删这一次**（默认）/ **删该周期项的未来实例** / **删整个周期**。
孤儿历史记录在待办页正常展示为"周期·{快照名}"，不提供跳转周期入口，可取消完成或删除。

### 4.6 其他约定

- 周期实例生成后，用户可单独修改该实例的标题、时间、完成状态，**不回写模板**。
- 修改 `start_date` / `interval_*` 后，已生成实例保持原日期不变，新规则仅对未生成轮次生效，`completed_count` 不重置（**Q8 采纳默认**），需在周期编辑页明示。
- 今日进度、待办列表均**包含**周期实例。
- 逾期的周期实例照常显示为逾期，且会阻塞该轮完结判定，需手动完成或删除。
