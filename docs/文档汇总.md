# 轻云 · 文档中心

> **轻云（`qingyun_todo`）**：一款 Flutter + SQLite 的单机版**待办软件**，iOS 风格 UI，无账号体系、无服务端、无网络依赖。
> 核心特色是**自定义天数周期**——一个周期可以有 N 天，且每一天能安排不同的事项。

**核对基线**：提交 `a2a63d8`（2026-10-20）；`lib/` 78 个 Dart 文件 / 13,416 行，`test/` 21 个文件 / **194 个用例**；schema **v2.2**（4 表）。
**实施进度**：Phase 0~6 已落地（待办 / 周期 / 日程 / 统计 / 通知），Phase 7（打磨与 1.0 发布）进行中。
**功能与未来计划**：见根目录 [README.md](../README.md) 的「Roadmap」，本文只做文档索引。

## 全局约定（所有文档与代码共用）

| 项 | 约定 | 示例 |
| :-- | :-- | :-- |
| 日期 | `YYYY-MM-DD`（本地时区） | `2026-09-25` |
| 时间 | `HH:mm`（24 小时制） | `09:30` |
| 时间戳 | `YYYY-MM-DD HH:mm:ss` | `2026-09-25 09:30:00` |
| 布尔 | `INTEGER` `0`/`1`（DB）、`bool`（Dart） | `1` |
| 颜色 | `#RRGGBB` | `#007AFF` |
| 枚举 | DB 存枚举 `name`；优先级小写、周期类型大写 | `high` / `MONTH` |
| 天序 `day_offset` | **0-based**，`0` = 周期第 1 天 | — |
| 轮次 `cycle_index` | **0-based**，`0` = 第 1 轮；来源周期删除后仍保留 | — |
| 术语 | 统一用"常规待办"（不用"日常"）、"周期项"（模板）、"周期实例"（生成的记录）、"孤儿记录"（来源周期已删的实例） | — |
| 文档元信息 | 写"核对提交 `<短 hash>` + 日期"；不写死文件数/行数/用例数（以 `flutter test` 输出为准） | — |
