## 1. 统一口径（先定口径，再定指标）

| 口径项 | 约定 | 说明 |
| :-- | :-- | :-- |
| "今天" | `date('now','localtime')` | 全部按本地时区，禁止用 UTC，否则晚间统计会错位一天 |
| 完成率归属 | 按 **`remind_date`** | "9/25 的完成率" = 提醒日为 9/25 的任务中已完成的比例 |
| 完成趋势归属 | 按 **`completed_at`** | "9/25 完成了几个" = 实际完成动作发生在 9/25 |
| 逾期 | `is_completed = 0 AND remind_date < today` | 实时派生，不入库 |
| 周期任务 | `source_type = 'PERIODIC'` | 与常规任务分开统计，避免周期刷量拉高整体完成率 |
| 空数据 | 分母为 0 时展示 `--` 而非 `0%` | 避免新用户看到"完成率 0%"的挫败感 |
| 硬删除记录 | **不计入**任何分母与分子 | 记录已物理移除；这是"删除"与"完成"的本质区别（Q5） |
| 孤儿周期记录 | **计入**周期完成率与历史统计 | 来源周期已删除但已完成实例保留，判定依据是 `source_type = 'PERIODIC'` 而非 `periodic_id` |

> ⚠️ 完成率与完成趋势分属两套口径（`remind_date` vs `completed_at`），混用会导致"完成率 100% 但趋势图为 0"的矛盾。UI 上需分别标注"应完成"与"实际完成"。

## 2. MVP 指标（建议首屏 6 项）

| # | 指标 | 定义 | 计算口径 | 展示形式 | 依赖字段 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| M1 | 今日完成率 | 今日应完成任务中已完成的占比 | `SUM(is_completed)/COUNT(*) WHERE remind_date = today` | 大数字 % + 环形 | `remind_date`,`is_completed` |
| M2 | 本周完成率 | 本周（周一起算）应完成任务完成占比 | 同上，`remind_date BETWEEN 周一 AND 周日` | % + 7 格点阵 | 同上 |
| M3 | 连续打卡天数 | 从今天向前回溯，每天都有 ≥1 条完成记录的最长连续天数（今天未完成时从昨天起算，不断链） | 按 `date(completed_at)` 去重后回溯 | 火焰图标 + N 天 | `completed_at` |
| M4 | 逾期任务数 | 未完成且提醒日早于今天 | `COUNT(*) WHERE is_completed=0 AND remind_date<today` | 红色数字卡，点击跳待办页逾期筛选 | `remind_date` |
| M5 | 待处理总数 | 全部未完成待办 | `COUNT(*) WHERE is_completed=0` | 数字卡 | `is_completed` |
| M6 | 周期任务完成率 | 周期实例的完成占比 | `SUM(is_completed)/COUNT(*) WHERE source_type='PERIODIC' AND remind_date<=today` | % + 副标题"仅统计已到期实例" | `source_type` |

**MVP 布局建议**：顶部 2 张大卡（M1 今日完成率环形 + M3 连续打卡），下方 2×2 小卡（M2/M4/M5/M6）。全部可用现有色彩系统实现（`#007AFF` 主色、`#34C759` 完成、`#FF3B30` 逾期），无需引入图表库。

## 4. 实现注意

1. **一次性聚合**：每个指标一条 SQL 取回结果，禁止在 Dart 侧遍历全表计算（万级任务会卡顿）。
2. **并行查询**：统计页 6 个指标用 `Future.wait` 并行，减少首屏等待。
3. **日期边界**：`julianday` / `strftime` 对 `YYYY-MM-DD HH:mm:ss` 字符串可直接解析，但格式必须严格一致（见 [02 §2 约定](./02-数据库设计.md)）。
4. **streak 计算**：SQL 回溯较繁琐，建议取 `SELECT DISTINCT date(completed_at) FROM tasks WHERE completed_at IS NOT NULL ORDER BY 1 DESC LIMIT 400`，在 Dart 侧回溯，逻辑更清晰且可单测（见 [04 §7](./04-数据层与CRUD.md)）。
5. **周期任务是否计入总完成率**：默认**分开统计**（M1/M2 只算全部任务，M6 单列周期）。若用户反馈周期刷量导致总完成率失真，可改为"仅常规任务完成率"，此为可调口径。
6. **空态**：无任何数据时统计页展示引导文案（"完成第一个待办后这里会出现数据"），而非一排 `--`。
